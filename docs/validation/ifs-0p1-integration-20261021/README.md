## 数据及字段覆盖

85 份原始文件的 SHA-256 全部正确；独立 ecCodes 解码核对了 **2,458 个有效原生场**
的全部中国区格点，数值逐值一致。起报、有效时间、参数编号、单位及网格均通过检查。
30 是变量并集，不能解释成每个时效都提供全部 30 个字段：

| 字段 | 原生覆盖及处理 |
|---|---|
| 其余 27 个变量 | 85/85 原生时效 |
| `fg10_max`，原参数 `10fg` | 67/85；93–144h 的同名参数未提供，原索引改发独立的 `10fg3` |
| `mn2t3_min`、`mx2t3_max` | 各 48 个样本，即 3–144h；0h 与 150–360h 保留 NaN |

已核对全部 18 个 93–144h 上游索引，并读取 +93h 原始 GRIB 头：`10fg3` 是
参数 **228028**，统计窗口 90–93h；原 `10fg` 是参数 **49**。+150h 的温度极值
改发 `mx2t6/mn2t6`。本次严格沿用原配置变量清单，**未把这些不同统计窗口的参数
混填到原字段，也未额外下载这三个参数作为生产字段**。后续扩展应分别新增独立字段。
证据见 `upstream-gust-full-interval.json`、`gust3-field-definition.json` 及
`upstream-gust-inventory.json`。这里的空值是所选参数的原生缺项，不表示上游完全
没有其他窗口的阵风或温度极值产品。

真实数据暴露的两个问题已限定在新适配器修复：

- 0.1° 经纬度的浮点误差会漏掉 70°E/55°N 边界。按 GRIB 微度精度规范化坐标后，
  正确保留 401×701 格点，气象数值未插值。
- f000 有两个指向 +3h 的全零最高/最低温预览。仅接收文件自身规范时效的场，避免
  并行拼接时覆盖真实 f003；独立验收确认只有这两个全零预览被忽略。
