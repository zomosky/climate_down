## 更早的高分辨率历史如何获取

公开 0.1° 自 2026-10-20 起开放，Google 前一周的缺口已逐起报检查。
本次还抽查 AWS 的 10-14、10-19 12z `ifs/0p1/oper/`，两者也为空。
更换公开镜像无法取得首发前不存在的同一套公开 0p1 文件。

**历史 IFS 原始高分辨率预报本身有归档途径。** ECMWF 的
[MARS 业务档案](https://www.ecmwf.int/en/forecasts/access-forecasts/access-archive-datasets)
支持按日期、起报、变量和时效查询原始场；
[官方网格文档](https://confluence.ecmwf.int/spaces/UDOC/pages/123799065/grid+-+keyword+in+MARS+Dissemination+request)
支持 `grid=0.1/0.1` 输出。应从当时的原始高分辨率归档场生成 0.1° 经纬网格，
并对齐模型版本、字段、统计窗口、单位、打包精度及原生时效；已有 0.25° 插值无法恢复原始细节。

可执行的获取路径：

- 使用公司或合作机构已有的相应 MARS 权限。
- 申请 ECMWF Archive 档案订阅；
  [官方订阅入口](https://products.ecmwf.int/shopping-cart/archive-orders/new)
  列出商用年订阅及有条件的科研免费访问，可按实际用途申请。
- 通过持有相应档案的数据服务商取得原始 IFS 历史；仍需核实所交付数据的分辨率、字段、覆盖和来源。

本次使用本机已有 ECMWF 凭据实际核验：**账号认证 HTTP 200，MARS 服务信息及一次 metadata-only
历史目录查询均返回 HTTP 403：`has no access to services/mars`**。这是账号的档案服务权限限制。
未购买服务、未提交气象场下载，认证信息已脱敏，见 [mars-access.json](mars-access.json)。

还需考虑档案许可的时效范围：
[MARS 官方访问规则](https://confluence.ecmwf.int/spaces/UDOC/pages/47290687/MARS+access+restrictions)
将“预报有效时间 + 24 小时尚未过去”的场列为受限。
普通历史档案权限下，前一周起报的部分远期时效现在仍受限；若要完整 0—360h，
全套通常需起报约 16 天后才都过期。例如 10-14 00z 的 +360h 场约到 10-30 00 UTC 后，
10-20 12z 的 +360h 场约到 11-05 12 UTC 后才越过这一门槛。实时/近实时授权另行适用。

[mars-sample-request.json](mars-sample-request.json) 是可复核的单场样例：
10-14 12z、+0h、2m 温度、中国范围、0.1° 网格。
当前缺少权限，样例未执行、没有返回 GRIB，也没有宣称已补齐历史。
